# Frontend contribution notes

- The GitHub repository is the source of truth. No Lovable runtime, connector, AI gateway, or editor integration is required.
- Keep API calls in `src/lib/api/`; parse responses with the Zod schemas in `types.ts`.
- The browser calls the public FastAPI base URL. Database access remains server-side in FastAPI; never put `DATABASE_URL`, a database password, or a Supabase service-role key in a `VITE_*` variable.
- Demo fixtures must be explicitly opted into with `VITE_DEMO_MODE=true`. Production should use `VITE_DEMO_MODE=false` and a real `VITE_API_BASE_URL`.
- `routeTree.gen.ts` is generated by the TanStack Start Vite plugin. Add route files under `src/routes/`; do not hand-edit the generated route tree.
- Keep the 300 MiB / 300,000-row streaming CSV validation in sync with the backend limits.
- Deploy the frontend from the `frontend/` root directory on Vercel. The FastAPI backend is a separate service.
